# Angelina Sefakor Avornyo — Portfolio

This repository contains a personal portfolio website for Angelina Sefakor Avornyo. The site uses a modern dark-chic aesthetic with baby-pink accents, a clean layout, and responsive design.

Preview
- Open `index.html` in a browser (double-click or serve with a local static server).
- Recommended: serve locally with `npx serve` or `python -m http.server` in the repo root for consistent asset loading.

How to preview locally
1. Clone the repo (if not already):
   git clone https://github.com/angesef/portfolio.git
2. Change into the folder:
   cd portfolio
3. Serve with a simple HTTP server (recommended):
   - Python 3: `python -m http.server 8000`
   - Or: `npx serve` (install if needed)
4. Open `http://localhost:8000` in your browser.
